# 色彩系统构建方法（生成 design-tokens.json 的色彩部分时必须遵循）

## 1. 从品牌色构建色阶

品牌只给一个主色时，按以下方法展开成 10 档色阶（50–900），不要孤立地用一个色值：

- 保持色相基本不变（可在深部微移 ±8° 增加层次），只调明度与饱和度。
- 明度锚点（近似 HSL 的 L）：`50≈97%, 100≈93%, 200≈85%, 300≈75%, 400≈62%, 500≈50%（≈品牌色）, 600≈42%, 700≈34%, 800≈26%, 900≈18%`。
- 浅端（50–200）降饱和防止刺眼；深端（700–900）略降饱和防止发黑发脏。
- **中性灰必须染上品牌色相**（饱和度 3–8%）：纯 #808080 系灰会让画面显得廉价、与品牌割裂。例如品牌蓝 → 灰阶用 `hsl(220, 6%, x%)`。这是"专业感"最廉价的来源之一。

## 2. 语义令牌（原型 CSS 只准消费这一层）

```
背景:   bg-page（页面底）· bg-surface（卡片/面板）· bg-subtle（分区/悬浮态底）· bg-inset（输入框/凹陷）
文本:   text-primary（灰900）· text-secondary（灰600）· text-tertiary（灰500，仅辅助信息）· text-disabled
        text-on-accent（品牌色上的文字，通常白）
边框:   border-default（灰200）· border-strong（灰300，输入框）· border-focus（品牌500）
交互:   accent（品牌600 用于文字/图标时保证对比；品牌500 用于大色块）
        accent-hover（+1 档深）· accent-active（+2 档深）· accent-subtle（品牌50，选中底色）
状态:   success/warning/danger/info 各配一组 {solid, subtle-bg, text}
        success≈green-600/50/700 · warning≈amber-500/50/800 · danger≈red-600/50/700 · info 可复用品牌
```

浅色模式的层次逻辑：`bg-page`（灰50 或纯白）→ `bg-surface`（白 或 灰50 反转）→ 边框区分层级。两者必须有可感知差异，否则卡片悬浮不起来。

## 3. 用色纪律（60-30-10）

- ~60% 中性底（页面/卡片背景），~30% 中性前景（文字、边框、图标），**≤10% 品牌色与状态色**。
- **一屏只有一个主操作**使用实心品牌色按钮；其余动作用描边/幽灵按钮。品牌色到处刷 = 层级失效，是视觉评审 blocker 判例。
- 状态色只用于状态（成功/警告/危险），不得挪作装饰；红色尤其不能用于非危险场景。
- 大面积高饱和背景禁止（导致文字对比与视觉疲劳双输）；需要品牌色氛围时用 `accent-subtle`（50 档）或 3–6% 透明度叠加。
- 文字禁用纯黑 `#000`（对比过硬发跳），用染色近黑（灰900，如 `hsl(220 15% 12%)`）；同理纯白底可微调为 `hsl(220 20% 99%)`。

## 4. 对比度预检表（生成令牌时逐对自检，勿等评审）

| 令牌对 | 阈值 | 依据 |
|---|---|---|
| text-primary / bg-page、bg-surface | ≥ 7:1（目标），≥ 4.5:1（底线） | wcag-1.4.3-contrast-minimum |
| text-secondary / 全部背景 | ≥ 4.5:1 | wcag-1.4.3-contrast-minimum |
| text-tertiary / 出现处背景 | ≥ 4.5:1（否则只能用于 ≥18.66px bold） | wcag-1.4.3-contrast-minimum |
| text-on-accent / accent | ≥ 4.5:1 | wcag-1.4.3-contrast-minimum |
| border-strong、图标、控件轮廓 / 相邻色 | ≥ 3:1 | wcag-1.4.11-non-text-contrast |
| border-focus / 相邻背景 | ≥ 3:1 | wcag-2.4.7 focus-visible |
| 状态色文字（success-text 等）/ subtle-bg | ≥ 4.5:1 | wcag-1.4.3-contrast-minimum |

品牌 500 常常无法同时满足"大色块好看"与"当文字够对比"——所以语义层区分 `accent`（文字/图标用 600）与大色块（500）。不要用同一个值硬扛。

状态信息必须叠加第二线索（图标/文字），不得只靠颜色（wcag-1.4.1-use-of-color）。

## 5. 深色模式（若范围内）

- 底不是纯黑：用染色深灰（如 `hsl(220 15% 10%)`）；层级靠**表面变亮**（+4–6% L/层）而非阴影。
- 全部颜色降饱和 10–20%，品牌色换用 400 档（深底上 500/600 会震颤）。
- 阴影几乎失效，改用 1px 亮边框（白 6–10% 透明度）区分层级。
- 深浅两套语义令牌同名不同值，组件 CSS 不改。

## 6. 常见廉价感来源（自查）

彩虹页面（>3 个非状态色相）· 纯灰中性色 · 单层大黑阴影 · 纯黑文字 · 品牌色当背景刷满头图 · 渐变滥用（一个页面 >1 处装饰性渐变）· 状态色饱和度不统一（红很艳绿很灰）。
