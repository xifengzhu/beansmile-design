# 风格方向库（提出 2–3 个视觉方向时从这里出发，按品牌与情境改造）

用法：不是照抄，是**起点**。每个方向给出人格、适用/禁用场景与具体令牌起点。专业模式选 2–3 个**彼此真正不同**的方向（不同 ≠ 换个主色：至少在密度、字体性格、圆角/阴影语言中有两项本质差异）。所有色值仍须过 color-system.md 的对比度预检。

---

## D1 瑞士极简（Swiss Minimal）

- **人格**：理性、精确、信息优先。**适用**：B2B 工具、数据产品、开发者产品。**别用于**：情感化消费品、儿童/生活方式。
- 色：黑白灰为主（灰染冷蓝相 `hsl(220 8% x%)`），品牌色仅 1 处强调；bg-page 纯白。
- 字：单一无衬线，字阶比率 1.2，标题 600 收紧字距；大量使用大小与字重对比而非颜色。
- 形：radius sm(4) 或 0；几乎无阴影，用 1px 边框与留白分层；密度中高。
- 动效：fast/克制，无装饰性动画。
- 关键手法：超大留白 + 严格网格 + 一处巨大的字号跳跃（display 直接 3× 正文）。

## D2 柔和生产力（Soft Productivity）

- **人格**：友好、可靠、降低压迫感。**适用**：SaaS、协作/管理后台、默认安全牌。**别用于**：需要强品牌记忆点的营销场景（容易"千站一面"）。
- 色：低饱和品牌色（蓝/紫/青），灰阶染品牌相；bg-page 灰50，卡片纯白。
- 字：无衬线 1.25 比率，标题 600；正文 15–16px。
- 形：radius md(8)–lg(12)；分层阴影 sm/md；卡片化布局。
- 动效：base 200ms，hover 轻抬（shadow +1 档，不位移）。
- 关键手法：`accent-subtle` 选中态 + 图标彩色/文字中性的平衡。

## D3 编辑杂志（Editorial）

- **人格**：有观点、内容为王、文化感。**适用**：内容平台、品牌官网、报告类。**别用于**：高频操作工具（衬线+宽留白拖慢扫读）。
- 色：米白纸感底（`hsl(40 20% 97%)`），近黑文字，一个饱和强调色（橘红/深绿/克莱因蓝）。
- 字：衬线标题（Songti/Noto Serif SC）+ 无衬线正文，比率 1.333，display 可到 60px+；行长严格 ≤ 35 汉字。
- 形：radius 0–sm；无阴影，用粗细横线（1px/3px）做分隔语言。
- 关键手法：首字下沉/超大引言、图文错位排版、大标题衬线与小注释无衬线的强对比。

## D4 深色专业（Dark Pro）

- **人格**：专注、技术、沉浸。**适用**：开发者工具、数据监控、创作工具。**别用于**：长文阅读、中老年用户为主的产品。
- 色：底 `hsl(222 15% 10%)`，表面每层 +5% L；品牌色用 400 档（亮而不噪）；文字 `hsl(220 15% 92%)`。
- 字：无衬线 1.2 比率 + mono 用于数据；tabular-nums 全开。
- 形：radius md(8)；无阴影，1px 白 8% 亮边框分层。
- 关键手法：一种高亮色（青/紫/绿 400）承担全部"活性"语义，数据可视化用同色相不同明度。

## D5 温暖人文（Warm Humanist）

- **人格**：亲切、有温度、被照顾感。**适用**：教育、健康、生活方式、社区。**别用于**：金融/审计等需要权威感的场景。
- 色：暖白底（`hsl(30 40% 98%)`），品牌色取暖相（珊瑚/杏/暖绿），灰阶染暖相。
- 字：圆润无衬线，比率 1.25，正文 16–17px 行高 1.75。
- 形：radius lg(12)–xl(16)；阴影暖染色、柔；插画风图标（2px 圆头描边）。
- 关键手法：不规则有机形状（blob）做装饰、真实摄影配暖色滤镜、微倾斜的贴纸感元素（≤2°，最多 1–2 处）。

## D6 活力消费（Playful Consumer）

- **人格**：年轻、即时满足、社交货币。**适用**：电商、社交、娱乐、活动页。**别用于**：效率工具、专业采购决策。
- 色：高饱和主色 + 1 个撞色（例如紫+黄绿），大胆用彩色底块；但正文区仍回归中性底保证可读。
- 字：无衬线 800/900 超重标题，比率 1.333；标题可全大写（西文）+0.05em。
- 形：radius xl(16)–full；胶囊按钮；粗边框（2px）+ 硬阴影（offset 4px 无模糊）可选。
- 动效：spring 感（scale 1.02 hover），slow 300ms 入场。
- 关键手法：贴纸/徽章元素、价格与 CTA 的超大字号对比、滚动横条（marquee）。彩色底块上文字对比必须逐块预检。

## D7 玻璃景深（Glass & Depth）

- **人格**：未来感、轻盈、精密。**适用**：AI 产品、创意工具展示、Pro 版营销页。**别用于**：信息密集表格后台（毛玻璃损失对比与性能）。
- 色：深色或渐变氛围底（品牌双色 135° 渐变，饱和度克制）；表面 `rgba(255,255,255,.08)` + `backdrop-filter: blur(20px)` + 1px 白 15% 边。
- 字：无衬线，浅色文字，标题可用渐变文字（仅 1 处）。
- 形：radius lg–xl；光感阴影（品牌色 glow `0 8px 40px rgb(品牌 / .25)`，仅主卡片）。
- 关键手法：分层景深（背景模糊圆斑 + 中景玻璃卡 + 前景实心控件）；正文与操作控件必须落在**实心表面**上保证对比达标。

## D8 新粗野克制版（Neo-Brutalist Lite）

- **人格**：直接、反套路、记忆点强。**适用**：设计/创意团队官网、差异化营销页、青年品牌。**别用于**：主流工具产品、无障碍要求极高的场景（需额外用心）。
- 色：纸白底 + 纯黑文字 + 1–2 个高饱和平涂色块；无渐变。
- 字：mono 或 grotesk，标题超大 700；正文仍保证 1.7 行高可读。
- 形：radius 0；2px 实线黑边框；硬阴影（`4px 4px 0 #000`）；hover 位移 -2px 模拟按压。
- 关键手法：可见网格线、表格式布局、标签化信息（全上边框）。对比度天然达标是它的隐藏优点。

---

## 方向提案的交付格式（确认门 C 用）

每个方向必须给：① 一句话人格 + 为什么适合本项目（引用 brief 中的用户/场景证据）；② 关键令牌表（主色/灰阶相/字族+比率/radius/阴影语言/密度）；③ 用**真实内容**渲染的同一关键页面预览（三方向同页对比，差异一目了然）；④ 风险与不适用提示。禁止给三个只换主色的"伪方向"——那是视觉评审的 warning 判例。
