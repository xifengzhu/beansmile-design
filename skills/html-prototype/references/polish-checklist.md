# 打磨清单（截图自评循环用）

用法见 SKILL.md 的"截图-自评-迭代循环"。每轮迭代：截图 → 对照本清单逐项过 → 列出命中的问题与修法 → 修改 → 再截图。**直到一轮零新增命中**才允许进入评审。评审 Agent 也用本清单反推，你漏掉的会变成 findings。

## A. 对齐与网格（截图上拉参考线看）

- [ ] 所有内容块的左边缘对齐到网格列，没有 1–3px 的漂移（截图放大看边缘）。
- [ ] 相同语义的元素（卡片、列表项、按钮组）尺寸与间距完全一致。
- [ ] 图标与相邻文字光学垂直居中（图标常常偏上 1–2px，需检查）。
- [ ] 页面左右边距对称；卡片内 padding 四边符合令牌。
- [ ] 文本基线对齐：同一行的标题与操作按钮基线/中线统一。

## B. 层级与扫读（眯眼看截图 3 秒）

- [ ] 眯眼测试：模糊状态下仍能立刻分辨"标题在哪、主操作在哪、从哪开始读"。
- [ ] 一屏只有一个视觉焦点级（实心主按钮/超大数字/头图三选一），没有多个元素抢焦点。
- [ ] 标题与正文至少差 2 个档位（字号或字重+颜色组合）；辅助信息确实退后（text-tertiary）。
- [ ] 区块之间的间距 ≥ 区块内部间距的 2 倍（否则边界糊掉）。
- [ ] 信息按用户任务排序：最重要的任务入口在首屏、在拇指区（移动）。

## C. 色彩与质感

- [ ] 全页非状态色相 ≤ 3；品牌色占比 ≤ 10%（60-30-10）。
- [ ] 中性灰带品牌色相，没有 #ccc/#999 这类裸灰与 #000 纯黑。
- [ ] 阴影是分层柔影或方向所定义的语言，没有默认丑影（`0 0 10px rgba(0,0,0,.5)` 之类）。
- [ ] 相邻表面层次可感知（bg-page vs bg-surface 有差异）。
- [ ] 状态色语义正确且饱和度协调（红绿黄看起来是一家人）。

## D. 排版细节

- [ ] 全部字号落在字阶档位上；行高符合档位定义（正文 1.6–1.8）。
- [ ] 正文行长 ≤ 35 汉字（约 640px @16px）；没有一行 60 字的"面条文本"。
- [ ] 数字用 tabular-nums（表格、金额、统计卡）。
- [ ] 没有 faux-bold/italic；标题字重是字体真实存在的档位。
- [ ] 大标题字距按规则调整（中文 +0.02em / 西文 -0.01~-0.02em）；没有孤行孤字（标题结尾单独一个字换行）。

## E. 状态完备（逐个交互元素过）

- [ ] 每个可点元素四态齐全：hover / active / focus-visible / disabled，且视觉可分辨。
- [ ] 空态、加载态（骨架屏尺寸=真实内容）、错误态、成功态都真实渲染在某个页面/入口上，不是只在代码注释里。
- [ ] 表单每个字段有错误示例可触发（或静态展示一个错误态字段）。
- [ ] 键盘 Tab 一遍：顺序合理、焦点环清晰可见、无陷阱、无不可达的可点元素。

## F. 内容真实度

- [ ] 没有 lorem ipsum / "测试测试"；文案接近真实业务（含真实长度的名称、金额、日期格式）。
- [ ] 极端内容已放入：一条超长标题、一个 0/空数据、一个大数字（百万级）、一个长用户名。
- [ ] 极端内容下无溢出、裁切、遮挡、换行灾难（截图确认）。
- [ ] 图片位有真实比例的占位（渐变/SVG 图形），无破图标、无 alt 缺失。

## G. 响应式（375 与 1440 两张截图对照）

- [ ] 375px：无横向滚动；边距 16；触控目标 ≥44；底部操作在拇指区；表格降级为卡片或可横滚且有提示。
- [ ] 1440px：内容区没被拉满到 100%（有 max-width），大屏留白得体而不是元素被撑大。
- [ ] 断点切换处布局自然（拿 768 左右也截一张看看），没有"两列挤成 1.5 列"的中间态。

## H. 手感与杂项

- [ ] transition 只作用于具体属性，时长 120–300ms；无 `transition: all`。
- [ ] 无布局跳动源：图片有宽高/aspect-ratio，加载态与内容态同尺寸，字体交换不抖（system 字体栈天然免疫）。
- [ ] favicon/页面 title 已设置（细节即完成度）。
- [ ] 控制台零错误、零 404 资源。

## 使用纪律

- 每轮自评产出一个简短记录（轮次、命中项、修复动作），供 Director 与评审核查迭代确实发生。
- 自评不能只挑 A/B 类硬伤——C/D 类"廉价感"问题才是与专业水准的主要差距，每轮必须正面检查。
