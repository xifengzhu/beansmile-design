# 方向执行手册（选定方向后、写原型前必读对应章节）

direction-library.md 回答"选哪个方向"；本文件回答"选定之后怎么做到位"。每个方向给：首屏构成、关键手法的具体配方、"敷衍 vs 到位"判别、翻车点。

使用者：
- **html-prototype Skill**：写代码前必读选定方向的整节；候选竞争的各版本必须分别落地本节"关键手法"中不同的构成组合。
- **视觉评审 Agent**：品牌辨识度维度按"敷衍 vs 到位"判别打分——方向落地流于表面是 warning 判例。

通用纪律：**关键手法至少落地 2 处，且落在首屏**。手法只出现在内页角落 = 没有落地。

---

## D1 瑞士极简

**首屏构成**：严格 12 列网格上的不对称构成——display 标题左对齐占 7–8 列，右侧大面积留白或一个精确的小元素（编号/图标）；首屏文字区上下 padding ≥ 120px。居中堆叠是这个方向最弱的构成，避免。

**关键手法配方**：
- 字号暴力跳跃：`display: clamp(48px, 7vw, 88px); line-height: 1.05; letter-spacing: -0.02em;`（西文/数字）；与正文形成 ≥4× 对比，中间不设过渡层级。
- 细线系统：全宽 1px 横线（`border-top: 1px solid var(--border-default)`）作为唯一的区块分隔语言，配 mono 小号大写栏目标签（`12px; letter-spacing: .08em; text-transform: uppercase;`）。
- 暴露的秩序：编号（01/02/03）、坐标式元信息、表格化布局——把网格本身当装饰。
- 唯一焦点：全页只允许 1 处品牌色，放在最重要的动作或数据上。

**敷衍 vs 到位**：敷衍 = 黑白灰配色 + 居中小标题 + 常规卡片（那只是"没上色的 D2"）。到位 = 一眼看到构成张力：巨大的字号对比、大胆的空、精确的线，让"少"看起来是自信而不是没做完。

**翻车点**：灰阶层次太多导致糊（最多 3 个灰度层级）；留白多但元素仍居中对称（张力消失）；忘记极简对对齐精度的放大效应——1px 漂移在这个方向里是显性 bug。

## D2 柔和生产力

**首屏构成**：产品界面用经典框架（侧栏 240 + 顶栏 56–64 + 内容区卡片流）；营销页用"居中标题 + 产品截图窗"（截图带 1px 边框 + radius lg + shadow-lg，可微透视）。

**关键手法配方**：
- `accent-subtle` 选中态：侧栏当前项 = 品牌 50 底 + 品牌 600 文字 + 500 字重，绝不用实心深色块。
- 图标彩色瓦片：`40px; border-radius: 10px; background: var(--accent-subtle);` 内放 20px 品牌色图标——功能卡/设置项的记忆点来源。
- 统计卡组合：13px 灰标签 → 31px tabular 数字 → 趋势徽章（`success-subtle` 底 + ↑12% 文字），三行固定节奏。
- 悬浮轻抬：hover 时 shadow sm→md，**不位移**。

**敷衍 vs 到位**：敷衍 = Bootstrap 感（默认蓝 + 白卡 + 纯灰底 + 无个性图标）。到位 = 灰阶与阴影都染品牌相、密度节奏统一（所有列表行同高）、至少一个自有记忆点（独特的空态插画语言 / 品牌色运用策略 / 定制图标瓦片色系）。

**翻车点**：这是"最安全也最容易千站一面"的方向——评审会按 rubric 把零记忆点判 warning；卡片套卡片（层级超过 2 层就糊）；圆角档位混用。

## D3 编辑杂志

**首屏构成**：编辑网格的不对称分栏（5/7 或 4/8），标题跨栏压住图片边缘形成错位；或"超大衬线标题全宽 + 下方双栏导语"。图文错位是核心：图不老实待在自己的列里。

**关键手法配方**：
- 衬线 display：`font-family: var(--font-serif); font-size: clamp(40px, 6vw, 76px); line-height: 1.15;` 中文大标题字距 `+0.02em`。
- 粗细线系统：3px 主分隔（section 级）+ 1px 次分隔（条目级），线是这个方向的图形语言。
- 首字下沉：`p:first-of-type::first-letter { font-size: 3.2em; float: left; line-height: .9; padding-right: 8px; font-family: var(--font-serif); }`
- 超大引言：pull-quote 用 h3 级字号 + 强调色 3px 左竖线 + 前后 48px 留白。
- 印刷细节：栏目眉（mono 12px 大写 + 日期）、文末方块符号（■）、编号目录。

**敷衍 vs 到位**：敷衍 = 普通页面换了个衬线标题。到位 = 网格有张力（错位、跨栏、不对称）、印刷细节成系统（眉/线/首字/引言至少 3 样）、纸感底色贯穿。

**翻车点**：正文别用衬线中文小字号（≤16px 的宋体屏显发虚，正文保持无衬线或 ≥17px 行高 1.8）；行长必须 ≤35 字（这个方向容器宽，最容易面条文本）；错位错到内容归属混乱是 blocker。

## D4 深色专业

**首屏构成**：面板化布局——工具栏 + 多面板网格（数据卡/图表/日志流），每个面板自带标题栏；营销页用"深色舞台中央一块发光的产品截图"。

**关键手法配方**：
- 分层公式：底 `hsl(222 15% 10%)`，每上一层 +4–6% L；层间再加 `1px solid rgb(255 255 255 / .08)` 亮边，**不用阴影**。
- 单一活性色：一种高亮色（青/紫/绿 400 档）承担全部交互语义——链接、选中、焦点、图表主线；第二色相只留给 danger。
- 数据字感：全部数字 `var(--font-mono)` + tabular-nums；大数字配 13px 灰标签；图表用同色相不同明度（400/600/800）而非多色相。
- 焦点 glow：`box-shadow: 0 0 0 3px rgb(<活性色> / .25)`，深底上比 outline 更自然（仍保留 outline 满足对比）。

**敷衍 vs 到位**：敷衍 = 浅色主题直接反色（黑底白字 + 还带着浅色的阴影和高饱和按钮）。到位 = 重新打光——层次靠亮度阶梯、全色降饱和、亮色惜用如金，画面安静且贵。

**翻车点**：正文用纯白（震颤，用 `hsl(220 15% 92%)`）；大面积 500/600 档品牌色块（深底上炸）；1px 亮边框透明度超过 12%（变成描边风）；长文阅读场景本来就不该选它。

## D5 温暖人文

**首屏构成**：大圆角内容卡（radius xl）+ 有机形状装饰垫底 + 插画/摄影位；标题行高宽松（1.3），整体密度比 D2 低一档；移动端优先的纵向节奏。

**关键手法配方**：
- 有机 blob：`border-radius: 42% 58% 60% 40% / 45% 40% 60% 55%; background: var(--accent-subtle);` 作头像底、插画垫、区块装饰（每屏 ≤2 个，透明度或 50 档色）。
- 暖染阴影：`0 4px 16px hsl(<品牌暖相> 40% 30% / .12)`——影子也有温度。
- 贴纸感：关键徽章/标签 `transform: rotate(-1.5deg)`，全页 ≤2 处，多了变乱。
- 圆头描边图标：单一图标集、`stroke-width: 2; stroke-linecap: round;`；配 2px 圆点列表符。
- 照片处理：暖色滤镜统一（`filter: saturate(1.05) sepia(.08)` 级别的克制量）+ 大圆角。

**敷衍 vs 到位**：敷衍 = 圆角调大的 D2。到位 = 暖相贯穿每一层（底暖、灰暖、影暖）、有机形状与圆头图标构成一致的"软"图形语言、文案口吻同步变暖（"你的"而非"用户的"）。

**翻车点**：暖浅底 + 暖灰文字最容易对比不达标（逐对预检）；甜腻过头（粉+黄+橙一起上）失去专业感——暖相也要守 60-30-10；blob 压到文字底下伤可读性。

## D6 活力消费

**首屏构成**：全出血色块 section 交替（每个 section 换底色，正文区回中性底）；超大商品图/主视觉 + 戏剧性价格标；贴纸徽章散布但服从网格。

**关键手法配方**：
- 色块节奏：section 底色按"品牌色 → 中性 → 撞色 → 中性"交替，**每块底色上的文字对比逐块预检**。
- 字号戏剧性：display 800/900 字重 + 比率 1.333 拉满；价格数字比商品名大 2–3 档；西文标题全大写 + `letter-spacing: .05em`。
- 大胶囊 CTA：高 56px、radius full、实心品牌色、可加 `4px 4px 0` 硬阴影；hover `transform: scale(1.02)`。
- 贴纸徽章：`rotate(±3deg) + 2px 边框 + 撞色底`，用于"限时/新品/折扣"，一屏 ≤3 个。
- 滚动横条：marquee（`animation: scroll 20s linear infinite` + 尊重 prefers-reduced-motion）放品牌口号/滚动优惠。

**敷衍 vs 到位**：敷衍 = 白底页面 + 一个亮色按钮 + 加粗标题。到位 = 色块有节奏、元素有运动感、价格与 CTA 的视觉音量碾压一切装饰——热闹但每一屏仍知道该点哪。

**翻车点**：装饰淹没转化动作（眯眼测试必须先看到 CTA）；色块上文字对比崩（这个方向的第一大 axe 失败来源）；全页都在喊 = 没有重点，热闹区之间要有安静区。

## D7 玻璃景深

**首屏构成**：三层景深舞台——背景层（双色渐变氛围 + 2–3 个大模糊光斑）→ 中景层（玻璃卡群）→ 前景层（实心控件与正文）。居中 hero + 环绕浮动玻璃卡是标志构成。

**关键手法配方**：
- 氛围底：`background: linear-gradient(135deg, <品牌深>, <品牌邻近色深>);` + 光斑 `position: absolute; width: 40vw; aspect-ratio: 1; border-radius: 50%; background: <品牌亮色>; filter: blur(100px); opacity: .35;`
- 玻璃卡配方（完整四件套，缺一不像玻璃）：`background: rgb(255 255 255 / .08); backdrop-filter: blur(20px); border: 1px solid rgb(255 255 255 / .15); box-shadow: 0 8px 32px rgb(0 0 0 / .25);`
- 光感强调：主卡 glow `0 8px 40px rgb(<品牌色> / .25)`（仅 1 处）；渐变文字 `background-clip: text`（仅标题 1 处）。
- 前景实心纪律：正文、表单、主按钮必须落在实心表面（深色 90%+ 不透明底），玻璃只承载展示性内容。

**敷衍 vs 到位**：敷衍 = 白卡上加个 blur、没有背景可透（blur 了个寂寞）。到位 = 透过玻璃能看到氛围层的颜色变化、三层景深可感、光源方向一致（光斑位置与 glow 方向同源）。

**翻车点**：`backdrop-filter` 大面积滥用（性能崩、层级糊，玻璃面 ≤ 视口 40%）；玻璃上放正文（对比必挂，axe 抓不到的也会被评审抓）；忘了无 backdrop-filter 支持的兜底（`@supports` 回退到实色）。

## D8 新粗野克制版

**首屏构成**：大字报式 hero（超大 grotesk/mono 标题顶格左对齐）+ 可见网格线的表格化内容区；元素之间用 2px 实线分隔而不是留白分组。

**关键手法配方**：
- 边框系统：全站统一 `2px solid #000`；卡片、按钮、输入框、表格同一描边语言；分组用"全上边框"标签（`border-top: 2px solid; padding-top: 8px;` + mono 大写小字）。
- 硬阴影按压：`box-shadow: 4px 4px 0 #000;` hover 时 `transform: translate(-2px,-2px); box-shadow: 6px 6px 0 #000;` active 反向压平——机械手感是灵魂。
- 平涂色块：1–2 个高饱和色（黄/绿/品红）做标签底、hover 底、选中底；无渐变无透明度。
- 暴露结构：可见网格线（`outline: 1px solid rgb(0 0 0 / .1)` 调试线转正）、序号、时间戳、`[标签]` 式元信息。

**敷衍 vs 到位**：敷衍 = 普通卡片加粗了边框。到位 = 整个页面像一张精心排的技术图纸：所有元素讲同一种粗直语言、色块惜用而狠、字号大得理直气壮，但行高与留白仍保证长读不累（"克制版"三个字就克制在这）。

**翻车点**：焦点态与 hover 态区分（都是位移会混淆，focus 用背景色变化）；黑白对比虽天然达标但**灰色一旦引入就要重新预检**；全页每个元素都硬阴影 = 噪声，只给可交互元素。

## 候选竞争的构成要求（对接 html-prototype 的执行竞争机制）

同一方向出 2–3 个候选版本时，**差异必须在构成层，不是换颜色**：

- 各候选从本方向"首屏构成"与 layout-composition.md 的构成模式中取**不同组合**（如 D3 候选 A 用错位分栏、候选 B 用全宽大标题+双栏导语）。
- 令牌（design-tokens.json）保持一致——竞争的是执行，不是重开方向。
- 每个候选都必须落地本方向 ≥2 个关键手法，否则不构成有效候选（选一个"没做手法的"来陪跑是自欺）。
