# 版式构成（把"排得整齐"拉到"排得有水准"的知识层）

type-and-spacing.md 管档位与网格（不出错），本文件管构成（出彩）。方向预览页、候选竞争的各版本、最终原型的首屏都按这里构建。视觉评审的"视觉层级/品牌辨识度"维度会用"构成是否有张力、记忆点是否落地"反推。

## 0. 两种语境，两套节奏

- **产品界面**（后台/工具/App）：任务密度优先。构成的水准体现在**节奏的一致**（行高、卡片、间距全站同拍）与**焦点的准确**（每屏一个明确的下一步）。不追求戏剧性。
- **营销/内容页**（官网/落地页/报告）：叙事节奏优先。构成的水准体现在**对比与留白的胆量**。本文件大部分手法服务这个语境。

## 1. 首屏构成模式（选一个，做足；居中堆叠是兜底不是默认）

| 模式 | 结构 | 适合 |
|---|---|---|
| **不对称分栏** | 文字占 7 列左，视觉占 5 列右（或反之）；文字块顶对齐视觉块的 1/4 处制造错落 | 通用首选，天然有张力 |
| **居中舞台** | 居中标题 ≤12 字 + 一句导语 + CTA + 下方产品截图窗（1px 边框 + radius lg + shadow-lg） | SaaS 产品、工具 |
| **全出血底** | 整屏色块/渐变/摄影打底，内容落左下或左中（不是死中央），底部留呼吸区 | 品牌感、活动页 |
| **编辑错位** | 超大标题跨栏压住图片边缘，图文互相侵入对方网格 | 内容、文化、作品集 |
| **产品实景** | 界面截图/设备样机占 50%+，可微透视（`perspective(1200px) rotateY(-6deg)` 以内） | 演示产品本体 |

通用参数：hero 高度 70–90vh 或内容自适应（禁止 100vh 死锁导致按钮被折叠线切）；首屏必须包含"标题 + 一句话价值 + 主 CTA"三件套且眯眼可辨。

## 2. 留白的胆量（业余与高手的最大肉眼差距）

- 营销页 section 上下 padding：**96–160px**（移动 64–96）。业余的标志就是 section 间距 40px——"怕空"。
- 标题的上方留白 ≥ 下方的 1.5–2×（标题属于它下面的内容，亲密性法则的区块级应用）。
- 关键元素（价格、核心数据、主 CTA）四周留白比普通元素多 1 档——留白就是聚光灯。
- 高密度区（功能网格、表格）之前刻意放一个低密度区（大标题 + 大留白），密度对比制造节奏——从头密到尾和从头空到尾一样单调。

## 3. 区块节奏（页面不是 section 的顺序堆叠）

- **宽窄交替**：全宽色块 section → max-width 720 的窄文本 section → 卡片网格 section。三种宽度轮换，滚动才有呼吸。
- **底色交替**：`bg-page → bg-subtle → bg-page → 品牌深色块（倒数第二屏 CTA 区）`。相邻 section 同底色时必须用间距或分隔线明确边界。
- **收尾定式**：倒数第二个 section 是全宽品牌色 CTA 区（深底 + 反白标题 + 实心按钮）——转化页的标准落点；最后是安静的 footer。
- 同类内容 ≥3 项用网格（2/3/4 列），≤2 项用分栏；网格列数一屏内不换。

## 4. 视觉记忆点菜单（每个交付至少落地 2 处，写进方向提案）

遮住 logo 还认得出来，靠的是这些（与 playbooks/<Dn>.md 分章手册的关键手法配合使用）：

1. **字号跳跃**：display 与正文 ≥3× 且中间无过渡档——"敢大"。
2. **品牌色运用策略**：不是"到处用一点"，而是一个可复述的规则（例：品牌色只出现在数字上 / 只做左侧竖条 / 只在 hover 时出现）。
3. **贯穿的图形语言**：一种形状或线条从头用到尾（D1 的细线、D3 的粗细线、D5 的 blob、D8 的 2px 框）。
4. **超大数字/字母**：把一个数据或首字母放大到失礼的程度（120px+），作为 section 的视觉锚。
5. **出血/异形元素**：一个元素故意破网格（卡片探出容器、图片切边、标签压线）——全页仅 1–2 处，破得越少越有力。
6. **独特空态/插画语言**：自定义 SVG 插画风格（见 assets-guide.md），空态是最便宜的品牌表达位。

反面：以上一个都没有 = rubric 的"零记忆点模板感"warning。

## 5. 动线与对齐张力

- **F/Z 动线**：信息页按 F（左对齐扫读）；转化页按 Z（左上标题 → 右上辅助 → 左下证据 → 右下 CTA）。主 CTA 落在动线终点而非几何中心。
- **50/50 分栏是最弱构成**：一律改 5/7、4/8 或 45/55——不对称产生方向感，对称产生静止感（只有"庄重"人格才要静止）。
- **重叠制造层次**：卡片压在色块边界上（上半在色块内、下半在白底上，`margin-top: -48px`）是最廉价有效的"设计过"信号。
- **对齐的例外要有理由**：一切左对齐的页面里，唯一居中的元素会成为焦点——把这个特权留给最重要的东西。
- 移动端：主 CTA 进拇指区（底部 1/3）；桌面 hover 才出现的操作在移动端必须常驻或收进菜单。

## 6. 图文关系（图不是填空题）

- 图片一律有意图尺寸：比例统一（16:9 或 4:3 或 1:1 全站选一为主）、`object-fit: cover`、圆角与卡片同语言。
- **图压文/文压图**：标题跨到图片上时，压住的深度 ≥ 标题高度的 1/3（压一点点像对齐失误）；压字区域需保证对比（图上加渐变遮罩 `linear-gradient(transparent, rgb(0 0 0 / .55))`）。
- 头像/logo 群（社会证明）统一尺寸灰度化或统一滤镜，杂色 logo 墙会毁掉配色纪律。
- 没有真图时按 assets-guide.md 生成有设计的占位（渐变+图形+噪点），**禁止灰底加"图片"二字**。

## 7. 构成自查（候选竞争与截图自评时用）

- [ ] 首屏采用了第 1 节的某个明确模式，能一句话说出是哪个。
- [ ] 记忆点 ≥2 处且在首屏或第二屏可见。
- [ ] 相邻 section 的宽度或底色至少有一项变化；全页 section 间距 ≥96px（营销页）。
- [ ] 有一处刻意的不对称或重叠；50/50 死对称分栏数 = 0。
- [ ] 主 CTA 在动线终点、视觉音量最大；眯眼 3 秒可辨。
- [ ] 没有任何区块是"标题+三个等宽小卡片"的默认模板连用 ≥3 次。
